# AI Trends Report Output Folders

โครงสร้างนี้ใช้สำหรับหา output ตามประเภทงานก่อน แล้วค่อยแยกตาม topic

## Canonical folders

- `reports/{topic}/` — source research reports
- `voice/{topic}/` — final generated voice/audio files when TTS is produced
- `audio_scripts/{topic}/` — scripts for voice/audio generation
- `assets/{topic}/` — structured combined assets for automation, usually JSON
- `social/{topic}/` — social post outputs

## File format policy

- Keep `.json` files for automation, API integration, dashboard, and future implementation.
- Add `.md` files when humans need to review content easily.
- Do not delete existing JSON when adding markdown review files.

## Topic naming

Use consistent snake_case topic folders when generated by automation, e.g. `joanna_wiebe`, `claude_code`, `NATEHERK` for existing legacy folders.
